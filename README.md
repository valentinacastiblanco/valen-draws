# Valen ✿ Draws · Landing / One Page

Trabajo 05 · Laboratorio UX/UI — HTML5 semántico + CSS3 responsive + JS (sin constructores visuales).

## Estructura
- `index.html` — header, nav, main (hero, sobre mí, galería, comisiones, cómo pedir, contacto), footer.
- `css/styles.css` — tokens (variables CSS = variables de Figma), Flexbox/Grid, media queries (Desktop 1920 / Mobile 393).
- `js/main.js` — menú mobile, parallax por capas (`data-speed`), scroll reveal (IntersectionObserver), validación accesible del formulario.
- `img/` — imágenes.
## Publicar en GitHub Pages
1. Crea un repositorio y sube todo el contenido de esta carpeta (que `index.html` quede en la raíz).
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. En 1–2 minutos queda en https://valentinacastiblanco.github.io/valen-draws/
